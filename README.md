# 🐞 BugLens AI

Advanced AI-powered debugging assistant for Python applications.

## Features

- Detect Python errors automatically
- Analyze root causes
- Generate detailed explanations
- Suggest code fixes
- Provide prevention recommendations
- Modern responsive interface
- Powered by Qwen2.5-Coder and Hugging Face

## Tech Stack

- Python
- Flask
- Hugging Face Inference API
- Qwen2.5-Coder
- HTML
- Tailwind CSS
- JavaScript

## Installation

```bash
git clone https://github.com/EMMA63G/BugLens-AI.git
cd BugLens-AI
pip install -r requirements.txt
python index.py
```

## Usage

1. Enter your Hugging Face API Token.
2. Paste your Python code.
3. Enter the error message.
4. Click **Diagnose Bug**.
5. Review the generated report.
