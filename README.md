# 📖 Project Overview

BugLens AI is an AI-powered debugging assistant designed to help developers quickly identify, understand, and resolve Python programming errors. The application analyzes code and error messages using a Large Language Model (LLM), then generates structured debugging reports that include the issue type, severity level, root cause, detailed explanation, suggested fixes, and prevention recommendations.

The project provides an intuitive and modern web interface built with Flask and Tailwind CSS, making bug diagnosis faster and more accessible for students, developers, and programming enthusiasts.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/EMMA63G/BugLens-AI.git
cd BugLens-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python index.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

---

# 🚀 Usage

1. Launch the application.
2. Enter your Hugging Face API Token.
3. Paste the Python code containing the issue.
4. Enter the corresponding error message.
5. Click **Diagnose Bug**.
6. Review the generated debugging report.

The report includes:

- Issue Type
- Severity Level
- Line Number
- Root Cause
- Detailed Explanation
- Suggested Fix
- Prevention Recommendations
